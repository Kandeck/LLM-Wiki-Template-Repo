# Obsidian LLM Wiki Template

这是一个 Karpathy `llm-wiki` 思路的 Obsidian 知识库模板。

## 使用方式

1. 将这个仓库克隆到本地。
2. 用 Obsidian 打开仓库文件夹。
3. 把原始资料放入 `RAW/`，或先放入 `INBOX/` 暂存。
4. 让 Codex 按 [[AGENTS]] 中的规则导入、更新、查询和健康检查。

## 保留内容

- `AGENTS.md`：LLM 维护规则。
- `使用说明.md`：中文使用说明。
- `index.md`：空模板索引。
- `log.md`：空模板日志。
- `WIKI/`：维护型 wiki 结构。
- `_system/`：模板、检查清单和系统说明。
- `.obsidian/`：基础 Obsidian 设置。

## 不包含内容

- 不包含任何 `RAW/` 原始资料。
- 不包含任何个人专题页面或导入后的资料摘要。
